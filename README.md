# KvikPlan

KvikPlan er en mobil bookingprototype udviklet i React Native med Expo.

Appen kombinerer booking med vandkapaciteten i en mobil bilplejevirksomhed. Kunden kan vælge servicepakke, bilstørrelse og tidspunkt, mens medarbejderen kan få overblik over dagens bookinger, vandstatus og genopfyldning.

## Kør projektet

Installer dependencies:

```bash
npm install
```

## Start projektet

npx expo start
